# MarkdownNote

Editor catatan berbasis Markdown dengan live-preview dan ekspor ke `.md` atau `.html`.

## Fitur
- Live preview Markdown saat mengetik
- Editor dengan textarea (sederhana) dan area preview
- Tombol bold, italic, link, gambar, daftar
- Ekspor ke file `.md` (Markdown)
- Ekspor ke file `.html` (rendered)
- Penyimpanan otomatis di LocalStorage
- Responsif

## Menjalankan
Buka `index.html` di browser, atau:
```bash
python3 -m http.server 8080
```
